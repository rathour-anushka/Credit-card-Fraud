# Credit Card Fraud Detection

This repository contains notebook for detecting fraudulent credit card transactions using machine learning.

## 📚 Dataset

We use the **Credit Card Fraud Detection dataset** available on Kaggle.

Due to file size restrictions on GitHub, the dataset (`creditcard.csv`) is **not included in this repository**.  
You can download the dataset manually from Kaggle using the link below:

👉 [https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)
